GM VOC POC — Architecture

Two tracks do classification and are compared so GM can pick the best. Topic modeling discovers new themes. The sentiment model is used alongside the winner.

1. The big picture

flowchart LR
    DATA["Call transcripts
(one row per sentence)"]
    subgraph CLS["Classification — compare & pick"]
        RE["Rule engine"]
        AI["ai_classify"]
    end
    TM["Topic modeling
(find new themes)"]
    SENT["Sentiment model"]
    OUT["Category + Sentiment
per sentence"]
    DATA --> RE
    DATA --> AI
    DATA --> TM
    DATA --> SENT
    RE --> CMP{{"Compare"}}
    AI --> CMP
    CMP --> OUT
    SENT --> OUT

2. Classification — rule engine

flowchart LR
    CM["category_model.json
(GM's categories + rules)"]
    IN["Sentences"]
    ENGINE["Rule engine
keyword / phrase / boolean match"]
    TAGS["Categories per sentence
+ which words matched"]
    CM --> ENGINE
    IN --> ENGINE --> TAGS

3. Classification — ai_classify (+ topic modeling)

flowchart LR
    IN["Sentences"]
    CLASSIFY["ai_classify
assign the 4 categories"]
    DISCOVER["topic modeling
embeddings + clustering"]
    TAGS["AI category tags"]
    THEMES["New themes"]
    IN --> CLASSIFY --> TAGS
    IN --> DISCOVER --> THEMES

flowchart LR
