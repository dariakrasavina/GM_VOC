GM VOC POC — Architecture

Three tracks. Tracks 1 and 2 both do topic tagging and are compared so GM can pick the best. Track 3 does sentiment and is used alongside the winner.

1. The big picture

flowchart LR
    DATA["Call transcripts
(one row per sentence)"]
    subgraph TOPICS["Topic tagging — compare & pick"]
        T1["Track 1
Rule engine"]
        T2["Track 2
AI functions"]
    end
    T3["Track 3
Sentiment model"]
    OUT["Topic + Sentiment
per sentence"]
    DATA --> T1
    DATA --> T2
    DATA --> T3
    T1 --> CMP{{"Compare
rules vs AI"}}
    T2 --> CMP
    CMP --> OUT
    T3 --> OUT

2. Track 1 — Rule engine (topic tagging)

flowchart LR
    RULES["rules.json
(GM's topic rules)"]
    IN["Sentences"]
    ENGINE["Rule engine
keyword / phrase / boolean match"]
    TAGS["Topic tags
+ which words matched"]
    RULES --> ENGINE
    IN --> ENGINE --> TAGS

3. Track 2 — AI functions (tagging + theme discovery)

flowchart LR
    IN["Sentences"]
    CLASSIFY["ai_classify
pick one of the 4 topics"]
    DISCOVER["embeddings + clustering
find brand-new themes"]
    TAGS["AI topic tags"]
    THEMES["Discovered themes"]
    IN --> CLASSIFY --> TAGS
    IN --> DISCOVER --> THEMES

4. Compare — rules vs AI

flowchart LR
    R["Track 1 tags"]
    A["Track 2 tags"]
    C["Compare job"]
    OUT["Agreement per topic
(where they match / differ)"]
    R --> C
    A --> C
    C --> OUT

5. Track 3 — Sentiment model

flowchart LR
    IN["Sentences"]
    LABEL["Bootstrap labels
(LLM, since we have none)"]
    TRAIN["Fine-tune DistilBERT
save to MLflow"]
    SCORE["Score sentiment
Very Neg .. Very Pos"]
    IN --> LABEL --> TRAIN --> SCORE
